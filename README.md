
# N-body simulation

Численное моделирование гравитационного взаимодействия N частиц на Python.

## О проекте

Программа моделирует движение системы из N тел, взаимодействующих друг с другом по закону всемирного тяготения. Траектории визуализируются в реальном времени с помощью Matplotlib.

## Метод

- Схема Верле (velocity Verlet) для интегрирования уравнений движения
- Softening-параметр (ε) для предотвращения численной сингулярности при r → 0
- Проверка сохранения полной механической энергии на каждом шаге
- Векторизация вычислений с помощью NumPy

## Файлы

- `nbody.py` — основная симуляция (Python, NumPy, Matplotlib)
